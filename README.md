# CEIS — Operating Systems & Core IT Labs

This repository is my **CEIS** coursework archive for hands-on operating system labs, command-line exercises, and core IT projects completed at **DeVry University** (*Associate of Applied Science in Cybersecurity and Networking, advancing into a Bachelor's degree*).

---

### What Goes Inside This Repository
Each folder inside this repository represents a **CEIS** course (such as *Operating Systems*, *Introduction to Technology and Information Systems*, and *Technology Career Foundations*) and contains:
- Lab objectives and system configuration tasks
- Windows and Linux (Ubuntu) command-line exercises
- Step-by-step troubleshooting documentation and key takeaways

---

### Core Skills Demonstrated
- **Operating Systems:** Navigating, configuring, and troubleshooting Windows and Linux (Ubuntu) environments
- **Command Line Interface (CLI):** Running diagnostics, managing files and directories, and configuring user permissions via Command Prompt, PowerShell, and Bash
- **Technical Documentation:** Recording clear, repeatable troubleshooting steps for Help Desk and IT Support workflows
