# CEIS 101 — Introduction to Technology and Information Systems

### Course & Lab Overview
During **CEIS 101 (Introduction to Technology and Information Systems)** at **DeVry University**, I studied and practiced foundational concepts across Linux operating systems, computer networking, wireless security, cloud and fog computing, data management, and the Internet of Things (IoT).

---

### Tools, Commands & Concepts Practiced
- **Lab Environment & Tools:** uCertify IoT Range (simulated Linux desktop environment), Linux Terminal, Linux File Manager, and Chromium
- **Linux System Inspection Commands:**
  - `cat /proc/cpuinfo` — Inspect detailed processor specifications
  - `cat /proc/cpuinfo | grep "model name"` — Filter system output to identify the active CPU model
  - `free -h` — Review system memory (RAM) usage in human-readable format
  - `lsmod` — Inspect loaded Linux kernel modules and drivers
- **Networking & Cloud Architecture:** LAN/WAN fundamentals, routers and switches, TCP/IP protocols and routing, wireless technologies (Wi-Fi, Bluetooth, Zigbee, LoRaWAN, 4G/5G), cloud vs. fog computing, and IaaS/PaaS/SaaS service models
- **Cybersecurity & Data Protection:** Firewalls, VPN encryption, authentication and authorization, MAC address filtering, wireless security, PII protection, phishing/social engineering awareness, and OS patching
- **IoT & Data Foundations:** Embedded systems, sensors/controllers/actuators, Real-Time Operating Systems (RTOS), structured vs. unstructured data, database concepts, and distributed data processing

### Key Takeaways & IT Support Relevance
- **Command-Line Hardware Diagnostics:** Practiced using Linux terminal commands to inspect CPU specifications, memory availability, and system files without relying solely on graphical menus.
- **End-to-End System Architecture:** Learned how edge sensors, local controllers, networks, fog nodes, and cloud platforms communicate to move and process data.
- **Security-First Mindset:** Connected foundational device configuration to core defenses—including encryption, access controls, wireless security, and timely OS updates.
- **Structured Troubleshooting:** Strengthened step-by-step verification habits essential for Help Desk, Desktop Support, and Junior Systems Administration roles.
